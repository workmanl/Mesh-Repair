Help and support

Common questions about MeshRepair.

Frequently asked questions

Which file formats can MeshRepair import and export?

MeshRepair imports binary STL, ASCII STL (detected automatically), and OBJ files. It exports repaired meshes in binary STL format, which is supported by standard 3D printing slicers.

When should I use Auto-Repair vs. Voxel Remesh?

Start with Auto-Repair, which fixes common defects such as open holes, flipped normals, duplicate faces, and unwelded vertices while preserving original triangle structure. If a model still has complex non-manifold geometry or self-intersections, use Voxel Remesh to rebuild the mesh from a 3D voxel grid into a closed, watertight surface.

What is included in the free tier vs. Pro Unlock?

Every diagnostic check, viewport mode, and repair tool works in the free tier, and your first 3 STL exports are free so you can test repaired files in your slicer. Pro Unlock is a one-time $9.99 purchase that unlocks unlimited STL exports.

How do I restore my Pro Unlock purchase on another Mac?

Make sure you are signed in to the Mac App Store with the same Apple Account used for the purchase, then use the Restore Purchases option in the app's upgrade window.

Are my 3D files uploaded to a server?

No. All file parsing, diagnostics, mesh repair, and exporting happen locally on your Mac. Your 3D files never leave your computer.

What should I do if a very large mesh is slow to process?

For high-polygon meshes (over 500,000 triangles), use the Simplify tool to reduce the triangle count to 50% or 75% first, then run Auto-Repair or Voxel Remesh.

How do I get help or report a bug?

Open the Help window in the app (Command-?), email hello@emrldlabs.com, or file an issue at github.com/workmanl/Mesh-Repair/issues.
